# Channel material

Working material for the Factopia Gist channel that is not part of the app.

| Item | What it is |
| --- | --- |
| [factopia-short-package/SKILL.md](factopia-short-package/SKILL.md) | The Claude skill that turns a topic into a complete Short: a verified fact with sources, a 30-second script for the voice, on-screen text, shot list, titles, description, hashtags and pronunciation notes |

The skill is saved in Claude as **factopia-short-package**; this is a backup
copy kept under version control. If the skill is changed in Claude, copy the
new text here too so the history shows what changed and when.

How it connects to the app:

1. Ask Claude for a Short package on a topic.
2. Paste the script into the **Studio** and add any names from the
   Pronunciation section to the **Pronunciation** screen.
3. Edit the video with the voiceover, then use **Captions** with the same
   script for exact wording.
